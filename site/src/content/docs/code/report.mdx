## Background information

Before you analyse a dataset, check that it contains what you expect and that it is consistent. A short report that a script makes automatically does this the same way every time, for 5 patients or for 5,000.

## To do

<Steps>

1. Extend the script so it makes a short report with:

   - the number of files per patient
   - the modalities in the dataset
   - a check that each patient folder contains files of only one patient

2. Print the report and save it to a text file.
3. Discuss with your partner: did you find anything unexpected? Use what you found in your suggestion for improving the storage and organisation of the data (section 1.3).

</Steps>
