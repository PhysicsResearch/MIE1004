## Background information

A graph gives a quick overview of a dataset. The `matplotlib` package makes simple graphs, such as bar charts and histograms, with a few lines of code. See the [Pyplot tutorial](https://matplotlib.org/stable/tutorials/pyplot.html) for examples.
