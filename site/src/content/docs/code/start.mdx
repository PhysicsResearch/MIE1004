## Background information

A DICOM file has two parts:

- the **header**, with metadata about the patient, the scanner and the acquisition, stored as tags such as `AcquisitionDate` or `PatientID`
- the **pixel data**: the image itself

The starting script reads DICOM files with the `pydicom` package. It has two functions:

- `read_metadata(folder)` lists the DICOM files in one folder, reads each file and collects its acquisition date. `ds.get("AcquisitionDate", "missing")` returns the value of the tag, or `"missing"` if the file doesn't have it.
- `main()` calls `read_metadata()` and prints the dates.
