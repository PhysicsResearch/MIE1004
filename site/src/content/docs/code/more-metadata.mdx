## Background information

The header of a DICOM file contains many tags. Each tag has a keyword, such as `PatientID`, `Modality`, `Manufacturer` or `SliceThickness`, and you read it in the same way as the acquisition date: `ds.get("Modality")`. To see all the tags of a file, print the dataset with `print(ds)`.

A table is an easier way to look at many values than a long list. The `pandas` package turns a list of dictionaries, one per file, into a table (a `DataFrame`).
