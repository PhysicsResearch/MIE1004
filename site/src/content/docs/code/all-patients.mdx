## Background information

So far the script reads one folder. Your download has several levels of folders: patient, study and series. Instead of setting each folder by hand, Python can go through all subfolders. For example, `Path(folder).rglob("*.dcm")` finds all DICOM files below a folder, however deeply they are nested.

The header also contains demographics, such as the sex (`PatientSex`) and age (`PatientAge`) of the patient. The age is stored as text, for example `083Y` for 83 years.
