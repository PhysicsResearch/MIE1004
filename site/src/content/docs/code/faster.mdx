## Background information

`pydicom.dcmread()` reads the whole file, including the pixel data, and `ds.pixel_array` turns the pixel data into an image. The pixel data is by far the largest part of a file, but you don't need it to read metadata.

With a few hundred files the difference is a matter of seconds. The full NSCLC-Radiomics collection has more than 52,000 images, and real projects can have millions, so reading only what you need matters.
