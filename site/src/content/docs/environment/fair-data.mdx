## Background information

FAIR is a set of principles for making research data reusable, by people and by machines. Data is FAIR when it is **F**indable, **A**ccessible, **I**nteroperable and **R**eusable. You will meet each letter during the lab.

| Principle         | What it means                                                                | Where you meet it in this lab                                                                 |
| ----------------- | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **F**indable      | The data has a persistent identifier and is listed in a searchable resource. | The dataset has a persistent identifier and is listed in a searchable public archive (TCIA).  |
| **A**ccessible    | The data can be retrieved through a standard, documented procedure.          | You download the scans with TCIA's documented tools: a manifest file and TCIA Data Retriever. |
| **I**nteroperable | The data uses shared formats and standards, so different tools can read it.  | The images use the DICOM standard, so scans from different vendors can be read the same way.  |
| **R**eusable      | The data comes with a clear licence, so you know what you may do with it.    | The dataset's licence and citation policy state what you may do with the data (section 2.4).  |
