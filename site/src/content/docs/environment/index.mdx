All work in this lab is done in Python, installed through Anaconda or Miniconda. Alongside the imaging content, the lab uses two good programming practices: **virtual environments** and **FAIR data**. This chapter sets up your computer and introduces both.

<Aside title="Using a different setup?">
	The examples in this lab use Anaconda or Miniconda together with VS Code. If you are used to
	another setup (for example `pip` with `venv`, PyCharm or Jupyter), you are welcome to use it, but
	you need to be able to adapt the instructions to your own environment.
</Aside>

## In this chapter

1. [Python with Anaconda or Miniconda](/environment/python/): install Python and check that it works.
2. [Virtual environments](/environment/virtual-environments/): create a separate environment for the lab and record it.
3. [FAIR data](/environment/fair-data/): the four principles you will meet during the lab.
4. [Code editor (VS Code)](/environment/vs-code/): set up VS Code and test everything with a short script.

<Aside type="tip" title="Save time in the session">
	Downloading and installing the software can take a while. If you can, complete this chapter
	before the session.
</Aside>
