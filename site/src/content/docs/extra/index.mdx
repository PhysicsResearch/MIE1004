## Background information

A CT series is a stack of 2D images, the slices, taken across the body: the **axial** view. If you put all the slices of a series together in a 3D NumPy array, you can also cut through the stack in the two other directions:

- **coronal**: seen from the front, dividing the body into a front and a back part
- **sagittal**: seen from the side, dividing the body into a left and a right part

To build the stack, the slices must be in the right order, and the file names don't tell you that order: in this dataset they are random IDs. Each file has an `InstanceNumber`, the number of the slice in the series, which you can use to sort them. Sometimes `InstanceNumber` is not available. Then `ImagePositionPatient` is useful: it gives the position of the slice in mm as three values (x, y, z), and z increases towards the head.

## To do

Write a new, simple script: you set one folder, the script reads it and shows one figure with the three views.

<Steps>

1. Set the folder of one CT series, as in section 3.1.
2. Read all the DICOM files in the folder, this time including the image (`ds.pixel_array`).
3. Sort the slices by `InstanceNumber`. If it is not available, sort them by the z value of `ImagePositionPatient` (the third value), from the highest (the head) to the lowest.
4. Stack the images into a 3D NumPy array with `np.stack()`. Its shape is (slices, rows, columns).
5. Take the middle slice in each direction. The axial one is `volume[n_slices // 2, :, :]`; work out the coronal and sagittal ones yourself.
6. Plot the three views next to each other in gray, with `plt.subplots(1, 3)` and `imshow(..., cmap="gray")`.
7. Look at the coronal and sagittal views: do they look squashed? The slices are 3 mm apart, but the pixels are only about 1 mm wide. Use the `aspect` option of `imshow()` with the ratio of `SliceThickness` to `PixelSpacing` to fix this.

</Steps>
